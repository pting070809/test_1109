# 安平港推估四草大橋出海口潮汐預測系統 (2026年11月)

本專案依據 **1. 中央氣象署 (CWA) 2026 年預測表** 與 **2. 安平港實測水文感測器**，建立水動力水文傳遞模型，精準推估台南**四草大橋（鹽水溪/四草湖出海口）**未來 7 天（2026-11-09 至 2026-11-15）之潮汐水位、高低潮時間與出海口水流狀態。

## 核心推估原理與水文模型

### 1. 中央氣象署 2026 年預測表 (CWA Astronomical Baseline)
- 基於中央氣象署安平潮位站（Station ID: 1152）主要調和分潮（M2、S2、K1、O1 等 8 組關鍵分潮）進行精密引潮力計算。
- 特徵：西南沿海混合潮（以半日潮為主，一日兩次滿潮、兩次乾潮，日不等潮顯著）。

### 2. 港口實測感測器 (In-Situ Sensor)
- 安平港防波堤高頻雷達波水位計（精度 ±0.5cm）與港外資料浮標。
- 捕捉真實海象中由東北季風吹降/吹升風壓、低氣壓所誘發之「氣象暴潮湧浪殘差（Meteorological Surge Residual, 約 +6 ~ +12 cm）」。

### 3. 四草大橋出海口推估模型 (Estuary Transfer Model)
四草大橋距安平港約 3.2 公里，位處鹽水溪與四草湖匯入外海的隘口：
$$h_{\text{sicao}}(t) = 1.025 \times h_{\text{anping\_astronomical}}(t - 10\text{min}) + 0.94 \times \Delta h_{\text{sensor\_residual}}(t) + 1.2\text{cm}$$
- **相位延遲（Phase Lag）**：潮波自外海向北傳播至河口，延遲約 **+10 分鐘**。
- **地形放大係數（Shoaling Amplification）**：河口喇叭狀水域收斂，振幅約 **1.025 倍**。
- **感測器殘差傳遞（Surge Coupling）**：外海氣象殘差向出海口傳遞比率約 **0.94**。

## 網頁版小軟體功能特色

1. **三線動態比對圖表**：
   - 藍綠色粗線：**四草大橋推估潮位**（即時動態響應）。
   - 琥珀色虛線：**安平港感測器實測潮位**（包含東北季風殘差）。
   - 靛青色細線：**氣象署安平港 2026 天文潮預報**。
2. **即時動態參數面板 (Dynamic Physics Tuning)**：
   - 使用者可自由拖曳調整「相位延遲（0~30分鐘）」、「河口放大係數（0.9~1.15倍）」及「感測器殘差權重（0~100%）」，全圖表與表格數據同步實時重算更新！
3. **出海口水流與航行安全指示**：
   - 依據潮位變化率（$\partial h / \partial t$）自動辨識出海口水流流態（漲潮湧入、退潮下洩、平潮轉流）以及推估流速（節 Knots），並給予出海口沙洲蚵棚航行提醒。
4. **雙基準面即時切換**：
   - 隨時在「海圖基準面 (CD)」與「台灣高程基準 (TWVD2001/MSL)」之間無縫切換。
5. **一鍵 CSV 匯出**：
   - 支援將當前設定之 7 天 168 小時數據直接下載為 CSV 檔。
